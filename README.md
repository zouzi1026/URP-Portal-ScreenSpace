# URP-Portal-ScreenSpace
在unity中，基于“屏幕空间投影”实现的传送门效果

由于unity向前兼容性较差（低版本无法打开高版本文件，基本上会报错），对于简单效果，作者选择使用unity2020版本。

目前效果在unity2020.3.49中得到验证，请使用URP10以上版本。
